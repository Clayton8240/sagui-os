# sagui8x16.txt - a fonte bitmap do SaguiOS, desenhada neste projeto.
#
# Cada caractere: uma linha "@X" (o caractere) ou "@nome" (para os pedaços
# usados na composição: acentos, i sem ponto, caixa), seguida de 13 linhas de
# 8 colunas. '#' = pixel aceso, '.' = apagado. As 13 linhas são as linhas 2 a
# 14 da célula de 16; as linhas 0, 1 e 15 ficam livres para os acentos das
# maiúsculas e para separar as linhas de texto.
#
# Medidas (em linhas deste arquivo): maiúsculas de 1 a 10, altura do "x" de
# 4 a 10, linha de base no fim da linha 10, descendentes em 11 e 12. Traços de
# 2 pixels, letras em 7 colunas, coluna 8 vazia para separar.
#
# As letras acentuadas não estão aqui: tools/mkfonte.py as monta juntando a
# letra base com o acento (blocos @agudo, @til...).
