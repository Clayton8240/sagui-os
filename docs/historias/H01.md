# H01. Preparar o ambiente

**Fase:** 1

## Objetivo

Instalar NASM, QEMU, ImageMagick, Python; validar o GCC freestanding; criar pastas, git, status.md e dashboard.

## Critério de aceite

`make` roda sem erro com um alvo vazio; dashboard abre no navegador.

## Resultado

**Concluída.**

- Ferramentas: NASM 2.16.01, GCC 13.3 (`-m32` freestanding, ver D001), QEMU 8.2.2, ImageMagick 6.9, Python 3, mtools.
- Estrutura de pastas da seção 5 do PRD, repositório git, `status.md`, `dashboard/`.
- `tools/status.py` mantém `dashboard/status.json`, `status.js`, `status.md` e estas páginas.
- Teste: `make vazio` imprime `SaguiOS: alvo vazio ok`; o JavaScript do painel foi executado no Node com um DOM simulado e desenhou todas as seções sem erro.
