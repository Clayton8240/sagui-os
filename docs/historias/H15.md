# H15. Pipes

**Fase:** 3

## Objetivo

pipe e duplicar, buffer no kernel, bloqueio de leitor e escritor, EOF.

## Critério de aceite

Dois processos transferem por pipe um texto maior que o buffer sem perda nem duplicação.

## Resultado

**Concluída.** Código em `kernel/fs/pipe.c` e `sis_pipe`/`sis_duplicar` em `kernel/fs/arquivos.c`; programas `userland/testes/pipe.c`, `gerador.c`, `consumidor.c`; decisão D015.

- `pipe(fds)` cria um buffer circular de 512 bytes no kernel com duas pontas (descritores); `duplicar(antigo, novo)` liga um descritor a outro arquivo aberto.
- Leitor bloqueia com o pipe vazio; escritor bloqueia com o pipe cheio; fim de arquivo quando todos os escritores fecham; "pipe quebrado" sem leitores.
- Teste `tests/h15_pipes.py` (programa `/testes/pipe`): um gerador escreve 20.000 bytes num pipe e o pai lê tudo (157 leituras, 0 bytes diferentes, fim de arquivo no final); no outro sentido o pai escreve 20.000 bytes para um consumidor, que confere byte a byte; escrever sem leitor dá erro.
