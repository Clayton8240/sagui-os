# H08. Sistema de arquivos SGFS

**Fase:** 2

## Objetivo

tools/mksgfs.py e leitor no kernel: listar pasta, abrir e ler arquivo.

## Critério de aceite

Teste interno lista as entradas do rootfs/ e lê o leia-me.txt inteiro.

## Resultado

**Concluída.** Código em `kernel/fs/sgfs.c`, `kernel/lib/caminho.c`, `tools/mksgfs.py`; formato descrito no cabeçalho do `mksgfs.py`.

- `mksgfs.py` monta o ramdisk a partir de `rootfs/`: cabeçalho com soma de verificação, tabela de entradas de 72 bytes com o caminho completo, dados alinhados em 16; textos convertidos para Latin-1.
- Leitor no kernel: confere assinatura, versão, limites e a soma; `sgfs_procurar`, `sgfs_proximo_filho` (filhos diretos de uma pasta), `sgfs_ler` com deslocamento, `sgfs_nome`.
- `caminho_resolver`: absoluto ou relativo, `.`, `..`, barras repetidas, tratando o caminho como pilha de componentes.
- Teste `tests/h08_sgfs.py` (autoteste `sgfs`): a lista que o kernel produz é igual à pasta `rootfs/` da VPS; o `leia-me.txt` lido em pedaços de 100 bytes é idêntico ao original (com acentos); casos de borda (inexistente, pasta, depois do fim, caminhos com `..`).
