# H12. Ring 3 e chamadas de sistema

**Fase:** 3

## Objetivo

TSS, segmentos de usuário, ring 3, int 0x80, validação de ponteiros.

## Critério de aceite

Programa em ring 3 escreve `Ola do ring 3!` e sai; `cli` no ring 3 encerra só aquele processo.

## Resultado

**Concluída.** Código em `kernel/nucleo/sistema.c`, `kernel/nucleo/chamadas_processos.c`, `kernel/arch/excecoes.c`, `kernel/arch/gdt.c` (TSS), `kernel/inc/abi.h`; decisão D012.

- TSS com a pilha do kernel de cada processo; segmentos de usuário na GDT; quadro inicial para o anel 3 (IOPL=0).
- `int 0x80` (porta acessível do anel 3) com a tabela de chamadas do PRD 4.5 (abi.h), com despacho que trata bloqueio com repetição (D010).
- `usuario_ok`/`usuario_texto`: validação de todo ponteiro vindo do anel 3.
- Exceção no anel 3 encerra só o processo, com a mensagem `[SaguiOS] Processo N (nome) encerrado: motivo`.
- Implementadas nesta história: `sair`, `pid`, `matar`, `esperar`, `dormir`, `tempo`, `data`, `info_sistema`, `aumentar_memoria`, `reiniciar` e `escrever` para a tela (o resto do grupo de arquivos na H14).
- Teste `tests/h12_anel3.py` (autoteste `anel3`): programa no anel 3 escreve `Ola do ring 3!` e sai com código 42 (o kernel recusou um ponteiro para a memória dele); `cli` no anel 3 encerra só aquele processo; ler a memória do kernel gera falta de página e encerra o processo; toda a memória volta.
