# H14. Arquivos e pastas graváveis

**Fase:** 3

## Objetivo

Camada gravável na RAM sobre o SGFS, tabela de arquivos por processo, terminal como 0 e 1.

## Critério de aceite

Teste em ring 3 cria, escreve, relê e apaga tmp/teste.txt; o mesmo com uma pasta.

## Resultado

**Concluída.** Código em `kernel/fs/vfs.c`, `kernel/fs/arquivos.c`, `kernel/dispositivos/terminal_es.c`; decisão D014.

- Árvore de nós na RAM montada a partir do SGFS, com cópia na escrita; criar, escrever (crescendo), sobrescrever (truncar), acrescentar, apagar (mesmo aberto), criar e remover pastas, renomear/mover.
- Tabela de 16 descritores por processo; arquivos abertos com contagem de referências; terminal como entrada 0 e saídas 1 e 2.
- Chamadas: `abrir`, `ler`, `escrever`, `fechar`, `posicionar`, `info_arquivo`, `criar_pasta`, `remover_pasta`, `apagar`, `listar`, `mudar_pasta`, `pasta_atual`, `renomear`, `modo_terminal`, `limpar_tela` (e `pipe`/`duplicar`, testados na H15).
- Teste `tests/h14_arquivos.py` (programa `/testes/arquivos`, no anel 3): 28 verificações, incluindo o critério do PRD (cria `tmp/teste.txt`, escreve, fecha, reabre, lê igual, apaga, confirma que sumiu; o mesmo com uma pasta), caminhos relativos, posicionar, truncar/acrescentar, alterar um arquivo do ramdisk e ponteiros para o kernel recusados.
- Erro encontrado: o próprio teste usava o deslocamento errado no `posicionar` (8 em vez de 9); corrigido no teste.
